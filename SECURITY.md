# Security Policy

## Scope
Nexus SOL AI is currently a public Paper / Simulation intelligence dashboard. It does not execute trades.

## Reporting
Please report suspected security issues privately to the repository owner rather than opening a public issue with exploitable details.

## Safety principles
- Never commit API keys, tokens, private keys, or credentials.
- Keep external links parameterized and encoded.
- Treat third-party market metadata as untrusted input.
- Keep trading execution disabled until separately reviewed and explicitly enabled.
